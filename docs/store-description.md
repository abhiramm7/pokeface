## Short description (≤ 80 chars)

Brutalist text-only watch face. Time, weather, calories, HR, sun. Day/night invert.

## Long description

Minimal Watch Face is a text-only, brutalist-modernist watch face built around
the micro-graphics aesthetic — small grotesque type, dense data, mathematical
placement. Every row is positioned by a layout solver that reads the actual
glyph widths and verifies each row fits inside the round display.

What's on the face:
• Live weather condition + temperature, lowercase
• Compact date with ISO week number
• Time in big Inter Medium
• Daily calories burned
• Compact step count
• Body battery
• Live heart rate
• Watch battery + sunrise / sunset times

The palette inverts at sunset: white on black during daylight, black on white
after sunset. Sun times are pulled from the watch's last known location via
Toybox.Weather.

Optimised for the Forerunner 265S 360×360 AMOLED. No bitmap art, no clutter.
